# OSINT Vault

Локальная записная книжка для расследований по открытым источникам.
Один HTML-файл, работает в браузере без установки и без интернета.

## Возможности
- Заметки в Markdown: заголовки, списки, чекбоксы, таблицы, код
- Ссылки между заметками `[[Название]]` с подсказками, обратные ссылки и граф связей
- Теги `#тег`, поиск, быстрый переход (Ctrl+K)
- Шаблоны: человек, домен, аккаунт, расследование, источник
- Автоматический поиск в тексте почт, IP, доменов, ссылок и хешей
  с копированием в безопасном виде (`hxxps://site[.]com`)
- Экспорт: резервная копия `.json` и папка `.md` в `.zip` (открывается в Obsidian)
- Светлая и тёмная темы

## Запуск
Открой `osint-vault.html` в браузере или запусти локальный сервер:

```bash
python -m http.server 8000
```

и перейди на `http://localhost:8000/osint-vault.html`.

## Где хранятся данные
Заметки лежат в `localStorage` браузера и никуда не отправляются.
Очистка данных сайта или смена браузера удалит их, поэтому делай резервные копии
через меню «Данные».

## Этика
Инструмент предназначен для работы с открытыми данными в рамках закона.
Не используй его для слежки за людьми и сбора их личной информации без причины.
